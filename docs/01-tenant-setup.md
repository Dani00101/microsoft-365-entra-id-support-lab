# Microsoft 365 og Entra ID – Tenant Setup

## Formål

Formålet med prosjektet er å bygge et praktisk Microsoft 365- og Microsoft Entra ID-labmiljø for å lære vanlige oppgaver innen IT-support og skybasert brukeradministrasjon.

## Miljø

- Microsoft 365 Business Premium – prøveversjon
- Tenant: CloudSupportLab
- Standarddomene: `CloudSupportLab.onmicrosoft.com`
- Microsoft 365 Admin Center
- Microsoft Entra ID
- Microsoft Intune skal konfigureres senere

## Abonnement

Microsoft 365 Business Premium-prøveversjonen ble aktivert.

Automatisk fornyelse ble deaktivert slik at abonnementet avsluttes ved utløp og ikke går over til et betalt abonnement.
