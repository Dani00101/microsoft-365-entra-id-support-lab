# Exchange – Shared Mailbox

## Formål

Formålet var å konfigurere en delt postboks i Microsoft 365 og gi en HR-bruker tilgang til å lese, administrere og sende e-post fra postboksen.

## Shared Mailbox

Følgende delte postboks ble opprettet:

- Navn: HR Support
- E-postadresse: `hrsupport@CloudSupportLab.onmicrosoft.com`

## Tilgang

Anna Hansen ble lagt til som medlem av postboksen.

Følgende rettigheter ble konfigurert:

- Read and manage (Full Access)
- Send As

Anna fikk dermed tilgang til å åpne og administrere postboksen og sende e-post som HR Support.

## Feilsøking

Ved første forsøk på å åpne postboksen ble feil e-postadresse brukt:

`hr.support@CloudSupportLab.onmicrosoft.com`

Den faktiske adressen var:

`hrsupport@CloudSupportLab.onmicrosoft.com`

Etter at korrekt adresse ble brukt, kunne postboksen åpnes som forventet.

## Verifisering

HR Support-postboksen ble åpnet i Outlook på web.

En testmelding ble sendt med:

`HR Support <hrsupport@CloudSupportLab.onmicrosoft.com>`

som avsender.

Mottakeren mottok meldingen med HR Support som synlig avsender.

Dette bekreftet at både Full Access og Send As fungerte.
